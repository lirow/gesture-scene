## Model

The Hand Landmarker model is a separate download, not part of the repository or distribution
build. `npm run setup:model` retrieves the official `float16/1` model for local use and verifies
SHA-256 `fbc2a30080c3c557093b5ddfc334698132eb341044ccee322ccf8bcf3607cde1`.
Review the model provider's applicable terms before use or redistribution. The runtime's
Apache-2.0 license is not asserted here as a license for the separate model artifact.

Official documentation: https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker
